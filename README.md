# *SLC1A2* rs4354668 and depression — forensic re-appraisal

Analysis code for:

> Karagöl A, Karagöl T. Internal replication failure and excess significance in a glial glutamate transporter candidate for depression: a forensic re-appraisal of *SLC1A2* rs4354668.

Every number in the manuscript and supplementary information is regenerated by
the scripts here. Nothing is transcribed by hand, and a test suite fails if any
reported value drifts.

---

## Quick start

```bash
pip install -r requirements.txt
make all     # every analysis + all three figures -> results/
make test    # 44 assertions covering every published value
make docs    # rebuild the manuscript and supplementary .docx (needs node, npm i docx)
```

Or individually, from the repository root:

```bash
python src/01_meta_analysis.py
python src/02_sanity_checks.py
python src/03_ledger_bias.py
python src/04_diagnostic_utility.py
python src/05_figure1.py
```

## Data

`data/genotype_counts.csv` holds the genotype counts for all three studies that
publish them, transcribed verbatim from the tables named in its `source_table`
column. It is the single source of truth: the scripts read it, they do not
embed their own copies.

Counts are stored harmonised to the A/C encoding. rs4354668 is reported in the
literature as A/C, as T/G and as −181A>C, because studies report opposite
strands. The alleles are not palindromic, so harmonisation is unambiguous:

```
A == T      C == G        (C/G is the low-promoter-activity allele)
```

Taking a published effect estimate without aligning the effect allele inverts
its sign, and an inverted null is indistinguishable from a correctly oriented
one. `src/pgc_lookup.py` implements the harmonisation with a frequency check
that halts if the reported effect-allele frequency diverges from expectation
by more than 0.15.

### The shared control series

Rodek 2022 and Merk 2019 report the *same* 462 controls — same counts, same
recruitment site, same bioethics approval number, same primers, same *Bcn*I
digest. `eaat.data.SHARED_CONTROLS` records this, and
`test_rodek_and_merk_share_one_control_series` fails if the two rows ever
diverge. Any synthesis treating them as independent double-counts 462 people.

## Tests

```bash
pytest -q        # 44 passed
```

The suite is not a formality. The paper documents a literature in which
reported numbers drifted from their sources, and it asserts every value it
publishes against the code that generates it — including the ones that
constrain the argument rather than support it:

- `test_heterozygote_deficit_largest_in_the_positive_series` asserts the
  confidence interval **includes zero**, so the observation stays
  hypothesis-generating and cannot quietly harden into a claim.
- `test_sign_test_cannot_reach_significance_at_k4` asserts *p* = 0.125 and
  *p* > 0.05, recording that directional consistency across four studies is
  not evidence.
- `test_tost_rejects_equivalence_at_the_published_effect` feeds the
  equivalence test the candidate-gene effect it is meant to exclude and
  asserts it says *not equivalent* — a check that the test is not a rubber
  stamp.
- `test_hartung_knapp_is_wider_than_dersimonian_laird` asserts the
  methodological claim the pooled result depends on.
- `test_genotyping_error_cannot_explain_the_finding` asserts that the
  mis-scoring rate required to produce the result stays implausibly high,
  so the paper's own suggested explanation cannot quietly become a claim.

Supplementary Tables S7–S12 are not written by hand. `make supp` regenerates
them as markdown from `src/07_emit_supp_tables.py`, and the supplementary file
is assembled from that output verbatim. Three transcription errors were found
and corrected by introducing this step.

## The confirmatory analysis has not been run

The manuscript states that the decisive test — interrogating existing
consortium data with roughly 2,600-fold more cases than the entire candidate
literature — has not been performed. `src/pgc_lookup.py` is the utility for
doing it:

```bash
python src/pgc_lookup.py resolve  --rsid rs4354668
python src/pgc_lookup.py extract  --sumstats <daner_or_ssf_file> --rsid rs4354668 --chr 11 --pos <pos>
python src/pgc_lookup.py tost     --beta <harmonised> --se <se> --bound 1.02
python src/pgc_lookup.py precision --ncase 688808 --ncontrol 4364225 --maf 0.41
```

PGC MDD2025 summary statistics are downloadable without application (the
non-23andMe releases are on figshare; the 23andMe-inclusive versions need a
separate approval that is unnecessary for a single-variant lookup). Use the
**clinical/interview-ascertained** release alongside the pooled one: it
matches the DSM-5 inpatient ascertainment of the study under examination and
forecloses the minimal-phenotyping objection.

`extract` has been verified to return an identical harmonised estimate from
the same result encoded both ways (daner `A1=A, OR=0.9988` and GWAS-SSF
`effect_allele=C, beta=+0.0012`). Its network-dependent paths have not been
exercised in CI.

## Environment

Python 3.13; numpy 2.4, scipy 1.17, pandas 3.0, matplotlib 3.10, pytest 8.3.
No other dependencies. Pinned in `requirements.txt`.

## Reproducing the paper from scratch

```bash
pip install -r requirements.txt && npm install docx
make all && make docs
```

This regenerates every table, every figure and both .docx files from
`data/genotype_counts.csv`. Nothing in the manuscript is transcribed by hand.
